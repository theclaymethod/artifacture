## Grounding

The Artifacture registry owns copy closure, versions, indexed contracts and examples. It checks exports and transitive imports. GraphicScene/GraphicMotion already own editable vector geometry and deterministic finite sampling. The media effects added this turn use explicit seconds/progress, with no internal clock. A caller owns decoded image/video input; a Three.js source owns its GPU resources and GLB loading lifecycle. The example page has one paused GSAP clock. Source files stay editable when copied.

The local f-explainer research gallery bundles actual source components without importing them. Its renderer uses a six-region measured glyph atlas and Three TSL WebGPU/WebGL2. Source adapters create a renderable source, update frame state and dispose. Existing source clocks integrate deltas and must be replaced. Procedural Strata/Arbor/Resonance, GLB adapters, native props and typography have real geometry; their original domain-specific chrome/assets do not define the reusable boundary.

## Comparison rubric

1. One model can feed shaded, shape-aware ASCII and particle output without rebuilding unrelated model code.
2. Explicit-time sampling can seek backward to the same output; asset readiness and disposal are real contracts.
3. A small public API hides camera, atlas, source/render lifecycles and backend fallback complexity.
4. Copy closure stays inspectable and license-safe; no private repo paths or unchecked third-party assets ship.
5. Diagram/poster/slide/video use the same semantic source and palette; glyph media is not misrepresented as editable SVG.

## Synthesis

The independent assessment scored shared ModelView ownership 22/25 and prepared-source/leaf ownership 18/25 against the five criteria above. Choose the shared owner: a fresh model factory preserves animation closures, semantic part references and disposal ownership. Cloned Three meshes share materials, and JSON-cloned userData does not preserve arbitrary references; a ref-counted template would add a second lifetime before there is evidence that caching is needed.

Keep model loading, matching and point sampling in bounded modules under one renderer. OrbitalText and TracePath remain independent SVG leaves. Living forms and props are ordinary factories outside the renderer closure. `AsciiObject` stays a compatibility adapter with its luminance-ramp options, while the new shape-aware treatment measures six glyph regions. No second model engine is retained.

The first implementation uses one standard Three WebGL renderer and a measured Canvas 2D shape matcher. This avoids speculative TSL/backend/color conversion work while preserving the selected shape-matching algorithm. Capture awaits model/font preparation and the exact requested draw. Source code remains editable; copied model blocks honestly carry their shared runtime closure.

Use source factories and caller-owned seconds for img2threejs models. Do not reconstruct semantic graphs through a private userData schema or start another clock. Initially, points support rigid mesh transforms and decoded alpha-aware imagery; unsupported skinned, instanced and morph geometry must report an actionable error rather than silently render a wrong cloud.
