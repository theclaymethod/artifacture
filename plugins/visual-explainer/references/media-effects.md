# Media effects

Discover and copy `ascii-image`, `ascii-sweep`, `ascii-object` and `vhs` with the component CLI. Read `docs/media-effects.md` in the ready runtime for complete contracts and the optional Blender starter. These are independently authored effects; do not import CanvasUI source into the public copy registry.

Use media effects as a presentation layer on prepared imagery. The caller owns time, source video decoding and the shared theme palette. Keep captions and teaching labels in a separate unfiltered layer. The glyph renderer uses a luminance ramp; shape-aware matching is a separately selected capability.

The selected `shape-ascii`, `particle-object`, `living-forms` and `procedural-props` now share ModelView. Read `docs/model-visuals.md` in the runtime. Capture awaits the exact requested draw. `AsciiObject` remains the original luminance-ramp adapter through that same owner; it does not maintain another GLB lifecycle.

For GLB input, use same-origin, uncompressed assets with embedded textures. Preserve source and license provenance. Use [procedural-models.md](procedural-models.md) to author low-detail model factories through the installed img2threejs skill. Use Blender when modifiers, rigging, simulations or baked footage improve the explanation.

Inspect the real start, reveal, hold and end. Seek backward to a previously sampled time and compare exported frames before using an effect in video. Do not infer video readiness from a wall-clock playground.
