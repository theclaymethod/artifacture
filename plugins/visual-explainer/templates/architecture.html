Collect, classify, and group feedback

Slack, GitHub, and email messages pass through a shared gateway. The pipeline classifies feedback, groups related items, and stores them for search and follow-up.

Message sources

  • Slack
  • GitHub
  • Email

Gateway

Router

Maps incoming messages to an agent through resolveRoute().

HTTP server

Accepts webhook events and API requests.

Processing pipeline

  1. Filter

    Remove duplicates, bots, and messages outside the allowlist.

  2. Classify

    Check relevance and extract structured feedback.

  3. Enrich

    Resolve the author and create an embedding.

  4. Cluster

    Find related feedback and store the result.

Stored records

feedback_items

Classification, embedding, source identifier, and cluster assignment.

clusters

Related items, centroid vectors, trends, and ticket links.

Search and follow-up

Agent tools

Search feedback and retrieve a trend’s source messages.

Actions

Create tickets and link follow-up work to source feedback.

Dashboard

Review clusters, severity, and changes over time.
