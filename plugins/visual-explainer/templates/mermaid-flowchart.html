  accTitle: Release pipeline
  accDescr: Checks run in parallel, then the image deploys to staging. Production requires a passing smoke test and approval.
  PUSH[Push to main] --> LINT[Lint and type check]
  PUSH --> UNIT[Unit tests]
  PUSH --> INTEGRATION[Integration tests]
  LINT --> BUILD[Build image]
  UNIT --> BUILD
  INTEGRATION --> BUILD
  BUILD --> STAGING[Deploy to staging]
  STAGING --> SMOKE{Smoke test passes?}
  SMOKE -->|Yes| APPROVAL[Approve release]
  SMOKE -->|No| ROLLBACK[Roll back staging]
  APPROVAL --> PROD[Deploy to production]
  PROD --> HEALTH[Check service health]
