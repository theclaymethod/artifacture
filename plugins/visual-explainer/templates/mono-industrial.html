A write-first ledger for request and response telemetry.

An illustrative architecture: persist each request before a handler runs, then let independent consumers replay the ledger.

Write path, read path, and the durability boundary.

The gateway acknowledges a request only after it is durable. Consumers keep their own offsets so they can recover independently.

Each module owns one side of the durability boundary.

Gateway

Validates requests and returns success after a quorum acknowledges the write.

Ledger

Stores an append-only log, partitioned by tenant.

Indexer

Reads the ledger and maintains query indexes. Rebuilds them by replaying records.

Query API

Serves queries from indexer state.

Write-path budget is 80ms end-to-end.
