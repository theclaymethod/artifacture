# Browser-native video

Use this recipe when a requested composition depends on browser-native figures or DOM behavior. Follow the current HyperFrames skill to create and render its native project. Keep HTML, CSS, media and timeline editable; use native timing and inspection. No Artifacture sequence conversion is required.

FFrames is the preferred starting route for native video. Browser dependencies are a concrete reason to select this alternative. Reuse ordinary media between the projects.

Resolve `hyperframes-animation`, `hyperframes-keyframes` and `hyperframes-audio` through the installed HyperFrames entry skill as needed. If available, `motion-doctrine`, `cut-the-curve`, `seam-craft` and `oversized-cursor` cover continuity, transitions, compositing and pointer-led demonstrations. Read only the relevant skill.
