# Explain an isometric mechanism

Start with a concrete question and inspect the evidence. Edit `src/story.mdx`; replace the example with one causal claim and an appropriate native figure. The generated document is an authoring starter, not evidence about a real system.

Use Hairline's public React exports for existing figures. For a new object, install its official authoring skill. Consult ISO Glow for causal lighting and iso-figure for isometric construction. Use Diagram Design for architecture/layout or Anatomy for mechanisms; do not redraw a native figure locally merely to unify APIs.

Keep white space, fine neutral strokes, one active accent and readable labels. Interactive source stays interactive; a film needs a native timeline or reusable media. Prefer native FFrames for video, and HyperFrames when the required scene depends on browser APIs.

Run `npm run dev`, `npm run build`, and `npm run export` from the same workspace. Inspect browser errors, figure interaction, a narrow viewport and the exported HTML. Import assets from source so Vite can bundle them. Files in `public/` and remote resources are not automatically made offline by standalone mode.
