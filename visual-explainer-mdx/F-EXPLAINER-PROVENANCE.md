## Source presentation correction

The living-form geometry and poses retain the source math. Their perspective camera (33 degrees), aspect-dependent fitting, a4c8af material (roughness .46, metalness .22) and hemisphere/key/rim/fill lights now retain the source values. No palette repaint or second default spin is applied. The WebGL/Canvas glyph delivery remains an adaptation of the original WebGPU shader; pixel parity is not claimed.

## Native living-form renderer

`native-ascii-renderer.tsx` preserves the original renderer core and six-region TSL shader. Only unrelated source adapters and their imports were removed. `native-living-form-source.ts` preserves the original Strata/Arbor/Resonance adapters with a relocated import. `NativeLivingForm` supplies the original settings and adds reduced-motion/visibility pause ownership. Both the WebGPU renderer and its native WebGL 2 fallback are the source implementation.

## Presentation/video clock shim

The native renderer now accepts optional `seconds`. The adapter replaces accumulated delta time with the same original absolute-time pose formula, fixes pointer lighting at its source midpoint in controlled mode, and writes the source reveal uniform directly. Native trophy capture samples the original 720 ms reveal formula. Geometry, glyph shader, material, lighting and camera remain source-owned. Omitted seconds preserves the native live clock. This is an explicitly documented shim; the copied source hashes above identify the original, not the adapted file hash.
